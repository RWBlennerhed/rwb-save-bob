# Save Bob v1.3 – Skill Over Luck

Save Bob is a fast-paced reflex game where precision and timing are everything.

Bob is surrounded by arrows. Your task is simple: tap the safe white arrows before it is too late.

But there is a catch.

One arrow is wrong. One mistake is all it takes.

---

## Gameplay

- Tap the safe white arrows  
- Avoid the deadly arrow  
- Survive each level  
- Save Bob  

The game becomes more intense and requires full focus.

---

## Smart Hint System v1.3

Version 1.3 introduces a subtle mechanic:

The deadly arrow may flash red for a very short moment.

It is not a clear hint. It is only a brief opportunity to react.  
You still have to rely on your own awareness and timing.

---

## Design Philosophy

- Skill over luck  
- Minimalist design  
- Fast response  
- No unnecessary complexity  

This is a game where your reflexes decide everything.
